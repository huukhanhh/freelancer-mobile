# Font source

Plus Jakarta Sans variable upright font, Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/plusjakartasans

Downloaded 2026-11-05. License: SIL Open Font License 1.1, see OFL.txt.
SHA256 (PlusJakartaSans.ttf): 89b3fb38aa0d275d7a731d0d817a4f1622b316b4d7fbdecdf02ee9099ff68bc8.

Only the upright family is currently used. Italic and Inter are deferred until
a verified screen needs them. No remote font requests at runtime.

Noto Sans Symbols 2 regular supplies the source Unicode ♡/♥ glyphs in job cards;
Plus Jakarta Sans lacks them on headless/Linux renderers. The rest of each card
keeps Plus Jakarta Sans. Source: Google Fonts ofl/notosanssymbols2, downloaded
2026-11-05; see NotoSansSymbols2-OFL.txt. SHA256:
7d5fb73b7ca67a6798101741f5d280a3d016a56a197afcd4199dbb57b4b82a21.
